# 报警服务子系统

## 已实现

- 统一 `AlarmEvent`、级别、活动/确认状态；
- 通过 SvcKit `EventLoop` 异步投递，不在网络或媒体回调内执行联动；
- 按来源、类型、最低级别过滤，并支持 cooldown 去重；
- 可组合的 `AlarmAction` 回调，用于录像、抓拍、PTZ、IO、通知等联动；
- 报警查询、确认、数量上限和追加日志持久化；
- generic_ipc 已接入系统启动、网络掉线和媒体管线失败事件。

## 边界

邮件、云平台、声光和 PTZ 的具体执行器需要由对应协议/外设服务注册；
报警核心不直接依赖 SMTP、厂商云 SDK 或 Platform HAL。
