

技术领域	具体技术/工具	在项目中的应用
构建系统	CMake (3.20+)	管理跨平台构建，生成VS、Makefile、Ninja等工程文件。使用Modern CMake实践。
依赖管理	vcpkg / Conan	管理第三方库（如Google Test、spdlog、glm、Bullet3）。
代码质量	Clang-Tidy, Clang-Format	代码静态分析与自动化格式化，统一代码风格。
单元测试	Google Test (GTest)	为核心模块编写单元测试，确保代码正确性。
性能分析	Valgrind / gperftools	内存泄漏检测与性能剖析。
持续集成	GitHub Actions	自动化运行Linux/macOS/Windows的构建、测试、分析任务。
文档生成	Doxygen + Sphinx	从代码注释生成API文档，并整合用户手册。
包管理	    CPack	生成安装包（DEB, RPM, ZIP等）。

# IPC 功能

实时视频分析：检测、分类、跟踪、区域规则、计数、OSD 和告警截图。
提示词驱动视觉：让 VLM 状态判断和 GroundingDINO 开放词汇检测与传统 CV 流水线协同工作。
可视化应用工作流：在浏览器中连接模型、规则、事件和输出动作。
边缘系统集成：管理场景任务，并通过 REST、WebSocket、MQTT 或 HTTP webhook 输出结构化事件。
